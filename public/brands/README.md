# Brand assets

These marks identify third-party Brand presets and do not imply endorsement.

- Supabase, Vercel, Tailwind, Resend, Stripe, Auth0, AWS, Browserbase, Clerk,
  Cloudflare, ElevenLabs, Firecrawl, Gemini, Mintlify, Nuxt, OpenAI, Prisma,
  and Trigger.dev SVGs were sourced from the MIT-licensed
  [`raycast/ray-so`](https://github.com/raycast/ray-so) project.
- Anthropic, Cursor, Docker, GitHub, Hugging Face, Linear, and Perplexity SVGs
  were sourced from the CC0-licensed
  [`simple-icons/simple-icons`](https://github.com/simple-icons/simple-icons)
  project.

- Files SDK is the project's own logo from the MIT-licensed
  [`haydenbleasel/files-sdk`](https://github.com/haydenbleasel/files-sdk)
  (`apps/web/public/logo.svg`), used verbatim.
- Flue and RivetKit are the projects' official marks, taken from
  [`flueframework.com`](https://flueframework.com/favicon.svg) and
  [`rivet.dev`](https://rivet.dev) respectively and reduced to single-colour
  silhouettes, because the picker paints them as CSS masks. Flue's solid
  field is inverted into a knock-out so the staggered squares stay visible;
  RivetKit's opaque backing plate is dropped for the same reason.
- The `plz` preset ships **no** mark. The project has no logo to source, and
  drawing one would put an invented glyph in front of users as if it were the
  project's identity. The picker falls back to an accent dot.

All product names and logos remain trademarks of their respective owners.
